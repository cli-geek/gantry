# Question fixtures

`greenhouse/` holds real Greenhouse job responses fetched once on 2026-10-24
with `curl` (about 30 requests, 2 s apart, Gantry's User-Agent). Each is
`GET https://boards-api.greenhouse.io/v1/boards/{token}/jobs/{id}?questions=true`
with the `content` field (job description HTML) removed by
`jq 'del(.content)'`; everything else is as served.

- `cloudflare-7695702.json`: custom questions and `compliance` (EEOC).

- `coinbase-8175363.json`: many custom select questions; `compliance` (EEOC).

- `discord-8806482002.json`: `demographic_questions` object (items carry
  `type` and `answer_options`) alongside `compliance`.

- `airbnb-7789554.json`: `compliance` and `demographic_questions` are `null`.

`harvest-*.json` is generated by
`cargo run -p gantry-discovery --example harvest_questions`. It is raw
material for the `variants` of the question bank. It is copied into
`data/questions/` only by a reviewed PR; nothing writes there automatically.
